Robot Face Emotions
Robot Face Emotions is a lightweight, interactive web project that simulates a robot face capable of displaying different emotional expressions through animated eye styles. Built with standard web technologies, this project demonstrates how CSS animations and simple JavaScript can be combined to create expressive, character-driven UI elements.

Features
Visually styled robot head with smooth floating animation

Visor with scanning light effect

Multiple emotional states:

Neutral

Happy

Sad

Surprised

Angry

Thinking

Sleeping

Typing

Emotion control panel with interactive buttons

Fully responsive layout

Pure HTML, CSS, and JavaScript implementation with no external libraries or dependencies

Technologies Used
HTML5

CSS3 (transitions, gradients, keyframes)

Vanilla JavaScript

How to Use
Clone or download this repository.

Open the index.html file in any modern web browser.

Use the on-screen buttons to change the robot's expression.

Use Cases
UI animation demos

Creative web interfaces

Educational tools for CSS/JavaScript learners

Concept prototypes for expressive avatars or assistants
